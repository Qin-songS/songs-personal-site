# songs.com

An English-first bilingual personal archive for thoughts, personal direction, résumé, and contact information.

## Local preview

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

The production site is built and deployed automatically from the private GitHub repository through Netlify.

## Content status

The visual system and bilingual structure are complete. Project history and personal media remain intentionally open for future additions.
